An entry for the make.fun bounty [news-image-20261119](https://make.fun/c/news-image-20261119): a Python program that writes one image summing up the world's news of Thursday, 19 November 2026. `main.py` copies the stored banner image to the output; `gen_image.py` is the generator that drew the banner during development.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

This writes `out/entry.png` (1024x1024 PNG). Running it twice writes the same bytes.
